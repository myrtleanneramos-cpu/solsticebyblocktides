# MAX Multi-Brand Operating System

## 🔥 1. EXECUTIVE SUMMARY
- **Tone Temple**: Launch Solana-native cultural OS with SONA AI scoring, Vault Keys, and Predict x Tone Race for creator-market fit, liquidity, and fan ownership.
- **Block Tides**: Deploy SEA-focused PR + growth engine with KPI-tied KOLs, media pipes, and partner-led revenue flywheel.
- **Solstice**: Scale premium-accessible beauty/wellness services with ritual-led packages, CRM-driven retention, and LTV-positive funnels.

## 🔥 2. SYSTEM BLUEPRINT
### Tone Temple
- **Architecture**: On-chain Vault Keys (NFTs) + SONA AI scoring service; Predict x Tone Race module for prediction markets; XP ladder + quests; treasury-controlled pools for rewards; APIs for creators/curators.
- **Data/Services**: Creator onboarding form → KYC/rights attestation → SONA scoring → vault minting → distribution to fans; Event bus triggers XP, payouts, notifications.
- **User Flows**: 
  1) Creator submits track → SONA score → mint Vault Key → set race parameters → publish. 
  2) Fan stakes TONE on races → gains XP/loot → secondary liquidity via AMMs. 
  3) Curator playlist quests → earn XP/fees → leaderboard impacts distribution weights.

### Block Tides
- **Architecture**: CRM (HubSpot/Notion) + media list DB + KOL roster; pipeline stages (Lead → Qualify → Scope → Close → Execute → Report); content factory with approval SLA; referral/partner module.
- **Data/Services**: Campaign briefs → content calendar → distribution (press, socials, KOL) → performance dashboards with UTM attribution.
- **User Flows**: 
  1) Inbound lead intake → 24h proposal → SLA-based execution. 
  2) KOL booking → content drops → tracking via unique codes. 
  3) Media syndication → clipping → client report.

### Solstice
- **Architecture**: Service catalog (rituals, naturals, signature experiences) + booking engine (Cal.com) + POS/CRM (Shopify/Stripe) + workflow automations (Zapier) + LTV model.
- **Data/Services**: Customer profile → consultation → ritual prescription → package upsell → membership billing → follow-up cadence.
- **User Flows**: 
  1) Discovery → quiz → recommended ritual → book. 
  2) In-clinic service checklist → product upsell → feedback capture. 
  3) Membership renewals triggered by usage/expiring credits.

## 🔥 3. TEAM PLAYBOOK
- **Roles**: GM per brand; Product/Engineering (Tone Temple), Growth/PR (Block Tides), Operations/Experience (Solstice); shared Data/BI + Finance.
- **Cadence**: Daily standups (brand-specific), weekly growth review, bi-weekly product/ops sync, monthly board packet.
- **KPIs**:
  - Tone Temple: Weekly Active Creators, SONA score delta, Vault Key GMV, Predict x Tone Race volume, XP engagement rate.
  - Block Tides: MQL→SQL conversion, campaign SLA hit rate, media placements/wk, CAC vs target.
  - Solstice: Bookings/day, AOV, repeat rate (D30/D60), membership attach %, NPS.
- **Workflows**: 
  - Intake → Prioritize → Sprint → Ship → Measure (all brands).
  - Approval SLAs: PR assets <24h, product specs <48h, service playbooks <72h.
